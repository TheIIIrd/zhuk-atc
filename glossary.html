    Словарь терминов и обозначений

    Коротко и простыми словами. По ссылке «подробнее» — полное объяснение в теории. Словарь пополняется с каждым модулем.


    Остаток a mod n
    Число r от 0 до n − 1 такое, что a = q·n + r. Пример: −7 mod 5 = 3. подробнее
    Сравнение по модулю a ≡ b (mod n)
    n делит a − b; то же самое: a и b дают одинаковый остаток. подробнее
    Кольцо вычетов ℤₙ
    Множество {0, 1, …, n − 1} со сложением и умножением по модулю n. Встречается также запись ℤ/nℤ. подробнее
    Поле
    Множество с четырьмя действиями арифметики (делить нельзя только на 0) и привычными законами. ℤₙ — поле ⇔ n простое. Строгое определение — в модуле 6. подробнее
    Конечное поле \(\mathbb{F}_p,\ \mathbb{F}_q\)
    \(\mathbb{F}_p = \mathbb{Z}_p\) при простом p. \(\mathbb{F}_q\) — поле из q элементов; q обязательно степень простого. 𝔽₄ ≠ ℤ₄. подробнее
    Противоположный элемент −a
    Число, дающее с a в сумме 0; в ℤₙ это n − a. В ℤ₂ −1 = 1, поэтому вычитание совпадает со сложением. подробнее
    Обратный элемент a⁻¹
    Число, для которого a·a⁻¹ ≡ 1. Существует ⇔ НОД(a, n) = 1. Деление: b / a = b·a⁻¹. подробнее
    Делитель нуля
    Ненулевой a, для которого a·b = 0 при некотором ненулевом b. Пример: 2·3 = 0 в ℤ₆. В поле делителей нуля нет. подробнее
    НОД, взаимно простые числа
    Наибольший общий делитель. Числа взаимно просты, если их НОД равен 1. подробнее
    Алгоритм Евклида (расширенный)
    Находит НОД последовательными делениями с остатком и коэффициенты u, v в НОД = u·a + v·n; отсюда обратный элемент. Тот же алгоритм для многочленов декодирует коды БЧХ и Гоппы. подробнее
    Соотношение Безу
    НОД(a, n) = u·a + v·n для некоторых целых u, v. подробнее
    Порядок элемента
    Наименьшее k ≥ 1, при котором aᵏ = 1. В 𝔽₇ порядок 2 равен 3. Порядок делит p − 1. подробнее
    Примитивный элемент
    Элемент, степени которого дают все ненулевые элементы поля; его порядок q − 1. Пример: 3 в 𝔽₇. Часто обозначается α. подробнее
    Малая теорема Ферма
    В 𝔽ₚ для любого a ≠ 0 верно \(a^{p-1} = 1\). подробнее
    Пространство векторов \(\mathbb{F}_q^n\)
    Все строки длины n из элементов \(\mathbb{F}_q\), всего \(q^n\) штук. Операции покоординатные. Запись 1021 означает (1, 0, 2, 1). подробнее
    Линейная комбинация
    Выражение \(c_1v_1 + \dots + c_mv_m\) с коэффициентами из поля. подробнее
    Сложение по модулю 2 ⊕
    XOR: 0 ⊕ 0 = 1 ⊕ 1 = 0, 0 ⊕ 1 = 1 ⊕ 0 = 1. Для векторов — покоординатно. подробнее
    Двоичный симметричный канал ДСК(p)
    Каждый бит независимо переворачивается с вероятностью p. подробнее
    Вектор ошибки e
    Разность принятого и отправленного слов: y = x + e. Число ошибок — вес e. подробнее
    Блочный код, кодовое слово
    Код длины n — подмножество \(C \subseteq \mathbb{F}_q^n\); его элементы — кодовые слова. При кодировании информационное слово длины k переходит в кодовое длины n. подробнее
    Параметры n, k, M
    n — длина кода, k — длина информационного слова (для линейных кодов — размерность), M — число кодовых слов (мощность). подробнее
    Скорость кода R = k/n
    Доля информационных символов среди передаваемых. подробнее
    Систематический код
    Кодирование, при котором первые (или последние) k разрядов кодового слова совпадают с информационным словом; остальные n − k разрядов — проверочные. подробнее
    Декодирование максимального правдоподобия
    Выбор кодового слова x с наибольшей P(y | x). В ДСК(p) при p < 1/2 — ближайшее к y кодовое слово. подробнее
    Расстояние Хемминга d(x, y)
    Число разрядов, в которых x и y различаются. Равно ‖y − x‖. подробнее
    Расстояние Ли ρ(x, y)
    Σ|xᵢ − yᵢ| при простом q. При q = 2 совпадает с расстоянием Хемминга, в общем случае d ≤ ρ. подробнее
    Вес ‖x‖
    Число ненулевых координат вектора. подробнее
    Метрика
    Функция расстояния: симметрична, неотрицательна (0 только для одинаковых), удовлетворяет неравенству треугольника. подробнее
    Шар и сфера \(B_r(a),\ S_r(a)\)
    Векторы на расстоянии ≤ r (шар) или ровно r (сфера) от a. \(|S_r| = \binom{n}{r}(q-1)^r\). подробнее
    Булев куб, слой, грань
    Булев куб — {0, 1}ⁿ. Слой — векторы одного веса. Грань — векторы с фиксированными n − k разрядами, запись вида ∗0∗10. подробнее
    Кодовое расстояние d(C)
    Наименьшее расстояние между двумя различными кодовыми словами. подробнее
    Число исправляемых ошибок t
    t = ⌊(d − 1)/2⌋. В программе — радиус упаковки кода. подробнее
    Число обнаруживаемых ошибок s, s′
    s = d − 1 в режиме обнаружения; s′ = ⌈(d − 1)/2⌉ в режиме исправления (s′ = t при нечётном d, t + 1 при чётном). подробнее
    Код с повторением
    Каждый символ повторяется n раз; декодирование голосованием. d = n, R = 1/n. подробнее
    Бинарная энтропия H(p)
    H(p) = −p log₂ p − (1 − p) log₂(1 − p). подробнее
    Пропускная способность C(p)
    Для ДСК(p): C(p) = 1 − H(p). Ниже неё можно передавать сколь угодно надёжно, выше — нельзя (теоремы Шеннона). подробнее
