    Конспект

    Блок 1.1. Арифметика по модулю

    • a mod n — остаток от 0 до n − 1; у отрицательных чисел остаток тоже неотрицательный: −7 mod 5 = 3.
    • a ≡ b (mod n) ⇔ n | (a − b). Остатки можно брать на любом шаге вычислений.
    • −a = n − a. В ℤ₂ вычитание = сложение = XOR.
    • Деление — умножение на обратный. a⁻¹ существует ⇔ НОД(a, n) = 1; находится перебором или расширенным алгоритмом Евклида.
    • ℤₙ — поле ⇔ n простое. Тогда пишут 𝔽ₚ. В поле нет делителей нуля, линейное уравнение имеет ровно одно решение. 𝔽₄ ≠ ℤ₄.
    • Примитивный элемент: его степени дают все ненулевые элементы поля. Порядок элемента делит p − 1, \(a^{p-1} = 1\).

    Блок 1.2. Расстояние и параметры кода

    • Схема: i → кодер → x → канал → y = x + e → декодер. Скорость R = k/n.
    • ДСК(p): P(y | x) = pᵈ(1 − p)ⁿ⁻ᵈ. При p < 1/2 МП-декодирование = ближайшее кодовое слово.
    • Расстояние Хемминга — число различающихся разрядов, это метрика; \(d(x, y) = \|y - x\|\).
    • \(|S_r| = \binom{n}{r}(q-1)^r\); \(|B_r|\) — сумма таких чисел по радиусам от 0 до r.
    • d(C) — минимальное расстояние между различными словами. t = ⌊(d − 1)/2⌋, s = d − 1, s′ = ⌈(d − 1)/2⌉.
    • Исправляет t ошибок ⇔ шары радиуса t вокруг слов не пересекаются ⇔ d ≥ 2t + 1.
    • Шеннон: C(p) = 1 − H(p). При R < C(p) есть коды со сколь угодно малой ошибкой, при R > C(p) — нет.

    Ключевые формулы

    \[ a = qn + r,\quad 0 \le r < n \]
    \[ b/a = b\cdot a^{-1} \]
    \[ P(y\mid x) = p^{d(x,y)}(1-p)^{\,n-d(x,y)} \]
    \[ |B_r| = \sum_{i=0}^{r}\binom{n}{i}(q-1)^i \]
    \[ \begin{aligned} t &= \left\lfloor\tfrac{d-1}{2}\right\rfloor, \\ s &= d-1, \\ s' &= \left\lceil\tfrac{d-1}{2}\right\rceil \end{aligned} \]
    \[ \begin{aligned} H(p) &= -p\log_2 p-(1-p)\log_2(1-p), \\ C(p) &= 1 - H(p) \end{aligned} \]

    Карточки

    Сначала ответьте вслух, потом переверните карточку: нажмите на неё или на кнопку «Показать ответ». Нажмите ещё раз, чтобы вернуться к вопросу.

    • Вопрос

      Чему равно −11 mod 4?

      Ответ

      1, потому что −11 = (−3)·4 + 1.

    • Вопрос

      Когда у a есть обратный по модулю n?

      Ответ

      Ровно тогда, когда НОД(a, n) = 1.

    • Вопрос

      Найдите 3⁻¹ в ℤ₇.

      Ответ

      5, так как 3·5 = 15 ≡ 1.

    • Вопрос

      Почему ℤ₉ — не поле?

      Ответ

      3·3 = 9 ≡ 0: у 3 нет обратного (НОД(3, 9) = 3).

    • Вопрос

      Что такое примитивный элемент поля?

      Ответ

      Элемент, степени которого пробегают все ненулевые элементы поля. Например, 3 в 𝔽₇.

    • Вопрос

      Почему МП-декодер в ДСК(p) при p < 1/2 выбирает ближайшее слово?

      Ответ

      P(y | x) = (1 − p)ⁿ·(p/(1 − p))ᵈ, а p/(1 − p) < 1, поэтому вероятность убывает с ростом d.

    • Вопрос

      Код имеет d = 6. Найдите t, s, s′.

      Ответ

      t = 2, s = 5, s′ = 3.

    • Вопрос

      Почему из «код исправляет t ошибок» следует d ≥ 2t + 1?

      Ответ

      Шары радиуса t вокруг кодовых слов не должны пересекаться; если бы d ≤ 2t, нашлось бы слово на расстоянии ≤ t от двух кодовых.

    • Вопрос

      Сколько векторов в шаре радиуса 1 в 𝔽₂⁷?

      Ответ

      1 + 7 = 8.

    • Вопрос

      О чём говорит обратная теорема Шеннона?

      Ответ

      При скорости R > C(p) = 1 − H(p) никакой код не даёт сколь угодно малой вероятности ошибки.
