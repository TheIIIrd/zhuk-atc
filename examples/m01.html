    Пример 1. Уравнение 5x + 6 = 2 в Z₇

    Пояснение

    1. Переносим 6. 5x = 2 − 6 = −4. Зачем: оставить слагаемое с x одно, как в школе.
    2. Приводим к остатку. −4 ≡ −4 + 7 = 3, то есть 5x = 3. Зачем: в \(\mathbb{Z}_7\) работаем только с числами 0…6.
    3. Находим 5⁻¹. Перебором: 5·3 = 15 ≡ 1, значит 5⁻¹ = 3. Зачем: делить по модулю — это умножать на обратный.
    4. Умножаем обе части на 3. x = 3·3 = 9 ≡ 2.
    5. Проверяем. 5·2 + 6 = 16 ≡ 2. Верно. Зачем: одна проверка ловит почти все арифметические ошибки.

    Ответ: x = 2. Решение единственное, потому что 7 — простое и \(\mathbb{Z}_7\) — поле.

    Пример 2. Обратный к 8 по модулю 21

    Пояснение

    Перебирать 20 вариантов долго, поэтому применяем табличный алгоритм Евклида. Каждая новая строка = позапрошлая − q · прошлая, где q — частное от деления позапрошлого остатка на прошлый. В каждой строке выполняется r ≡ x·8 (mod 21).

    СтрокаrqxЧто произошло
    старт21—021 ≡ 0·8
    старт8—18 ≡ 1·8
    1520 − 2·1 = −221 = 2·8 + 5
    2311 − 1·(−2) = 38 = 1·5 + 3
    321−2 − 1·3 = −55 = 1·3 + 2
    4113 − 1·(−5) = 83 = 1·2 + 1

    Получили остаток 1, значит НОД(8, 21) = 1 и обратный есть: 8⁻¹ ≡ 8 (mod 21). Проверка: 8·8 = 64 = 3·21 + 1. Неожиданно, но верно: 8 обратен сам себе.

    Почему таблица работает

    Если r₁ ≡ x₁·8 и r₂ ≡ x₂·8, то r₁ − q·r₂ ≡ (x₁ − q·x₂)·8. Новый остаток выражается через 8 с коэффициентом, посчитанным тем же действием. Когда остаток стал равен 1, коэффициент x и есть обратный.

    Пример 3. Вектор ошибки над F₅

    Пояснение, по образцу примера из лекции 1 «Введение»

    Передали x = 3140, приняли y = 0142. Найти вектор ошибки и число ошибок.

    1. e = y − x покоординатно: (0 − 3, 1 − 1, 4 − 4, 2 − 0) = (−3, 0, 0, 2).
    2. Приводим по модулю 5: −3 ≡ 2. Получаем e = 2002.
    3. Число ошибок — вес вектора ошибки: ‖e‖ = 2. Это и есть расстояние Хемминга d(x, y) = 2.
    4. Проверка: x + e = (3 + 2, 1, 4, 0 + 2) = (5, 1, 4, 2) ≡ 0142 = y.

    Пример 4. Декодирование максимального правдоподобия

    Курс: пример из лекции 1 «Введение»

    Двоичный код задан кодированием 00 → 00001, 01 → 01010, 10 → 10111, 11 → 11100. Канал — ДСК(p) с p < 1/2. Принято y = 10101. Что передавали?

    1. Считаем расстояния от y до каждого кодового слова — сравниваем разряды.
      Кодовое слово xd(y, x)\(P(y \mid x) = p^{d}(1-p)^{5-d}\)
      000012p²(1 − p)³
      010105p⁵
      101111p(1 − p)⁴
      111002p²(1 − p)³
    2. Сравниваем вероятности. При p < 1/2: p⁵ < p²(1 − p)³ < p(1 − p)⁴. Зачем: МП-декодер выбирает максимум P(y | x). Каждое лишнее несовпадение умножает вероятность на p/(1 − p) < 1.
    3. Вывод. Максимум у x = 10111 — это ближайшее кодовое слово. Значит, передавали информационное слово i = 10, а ошибка была одна: e = y ⊕ x = 00010.

    Пример 5. Параметры кода и декодирование

    Пояснение

    Код C = {00000, 11100, 00111, 11011}. Найти d, t, s, s′, скорость и декодировать слова 10100 и 10001.

    1. Все попарные расстояния (пар 4·3/2 = 6):
      • d(00000, 11100) = 3, d(00000, 00111) = 3, d(00000, 11011) = 4;
      • d(11100, 00111) = 4, d(11100, 11011) = 3, d(00111, 11011) = 3.
    2. Минимум: d = 3. Значит t = ⌊2/2⌋ = 1, s = 2, s′ = ⌈2/2⌉ = 1.
    3. Скорость. Слов M = 4 = 2², то есть k = 2 информационных бита при n = 5: R = 2/5.
    4. Декодируем y = 10100. Расстояния до слов кода: 2, 1, 3, 4. Ближайшее единственное — 11100, одна ошибка во 2-м разряде. Это гарантированно исправимо, ведь t = 1.
    5. Декодируем y = 10001. Расстояния: до 00000 — 2, до 11100 — 3, до 00111 — 3, до 11011 — 2. Два ближайших слова на одинаковом расстоянии 2: ошибка обнаружена, но не исправима. Это согласуется с теорией: двух ошибок больше, чем t = 1.

    Наблюдение на будущее

    11100 ⊕ 00111 = 11011 — сумма двух слов кода снова в коде. Такие коды называются линейными (модуль 3), и у них d равно минимальному весу ненулевого слова: здесь минимальный вес как раз 3.

    Пример 6. Код с повторением: во сколько раз меньше ошибок

    Курс: пример из лекции 1 «Введение»

    1. Голосование по трём битам ошибается, если испорчены ровно 2 бита (3 способа выбрать какие) или все 3: \(P_{\text{ош}} = 3p^2(1-p) + p^3 = 3p^2 - 2p^3\).
    2. При p = 0,01: 3·0,0001 − 2·0,000001 = 0,0003 − 0,000002 = 0,000298.
    3. Без кодирования ошибка в бите случается с вероятностью 0,01. Отношение 0,01 / 0,000298 ≈ 33,6 — ошибок стало примерно в 34 раза меньше.
    4. Цена: на один бит информации передаём три, скорость R = 1/3.

    Пример 7. Объём шара и сколько слов поместится

    Пояснение, задел на модуль 4

    1. Шар радиуса 1 в \(\mathbb{F}_2^7\): центр плюс 7 соседей (меняем один из 7 разрядов): |B₁| = 1 + 7 = 8.
    2. Если код исправляет 1 ошибку, шары радиуса 1 вокруг кодовых слов не пересекаются. Значит, слов не больше 2⁷ / 8 = 128 / 8 = 16.
    3. Код Хемминга (7, 4) на главной содержит ровно 2⁴ = 16 слов: шары вокруг них покрывают весь куб без зазоров. Такие коды называются совершенными (модуль 4).
