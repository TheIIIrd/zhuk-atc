    Задача 10

    ★★★ сложная

    Докажите, что при составном n кольцо \(\mathbb{Z}_n\) не является полем: предъявите элемент без обратного.

    Заметки есть запись

    Решайте в тетради, а сюда запишите итоговый ответ или место, где застряли. Заметка хранится в этом браузере.

    Подсказка

    n = a·b, где 1 < a, b < n. Чему равно a·b в \(\mathbb{Z}_n\)?

    Решение

    Пусть n = a·b, 1 < a, b < n. Тогда a·b ≡ 0, но a ≢ 0 и b ≢ 0. Если бы у a был обратный, то b ≡ a⁻¹·a·b ≡ 0 — противоречие. Ещё короче: НОД(a, n) = a > 1, и по теореме обратного нет.

    Задача 11

    ★★★ сложная

    Решите x² = 1 в \(\mathbb{F}_{11}\) и в \(\mathbb{Z}_8\). Почему число решений разное?

    Заметки есть запись

    Решайте в тетради, а сюда запишите итоговый ответ или место, где застряли. Заметка хранится в этом браузере.

    Подсказка

    x² − 1 = (x − 1)(x + 1). Вспомните задачу 9.

    Ответ

    В \(\mathbb{F}_{11}\): x = 1 и x = 10. В \(\mathbb{Z}_8\): x = 1, 3, 5, 7.

    Решение

    В поле (x − 1)(x + 1) = 0 ⇒ x − 1 = 0 или x + 1 = 0 (делителей нуля нет), то есть x = 1 или x = −1 = 10. В \(\mathbb{Z}_8\): 1² = 1, 3² = 9 ≡ 1, 5² = 25 ≡ 1, 7² = 49 ≡ 1. Например, при x = 3: (x − 1)(x + 1) = 2·4 = 8 ≡ 0, хотя оба множителя не ноль. Многочлен степени 2 над полем имеет не больше двух корней, а над \(\mathbb{Z}_8\) это неверно.

    Выразите ‖x ⊕ y‖ через ‖x‖, ‖y‖ и число разрядов, где у обоих векторов стоят единицы.

    Задача 20 (программа, № 2)

    ★★★ сложная

    «Найти максимально возможную мощность двоичного кода длины n, обнаруживающего одну ошибку. Доказать, что существует всего два различных двоичных кода длины n и максимальной мощности 2ⁿ⁻¹, обнаруживающих одну ошибку.»

    Заметки есть запись

    Решайте в тетради, а сюда запишите итоговый ответ или место, где застряли. Заметка хранится в этом браузере.

    Подсказка 1

    Обнаруживать одну ошибку ⇔ d ≥ 2 ⇔ в коде нет двух соседних векторов. Разбейте куб на пары векторов, отличающихся только последним разрядом.

    Подсказка 2 (для единственности)

    В коде мощности 2ⁿ⁻¹ из каждой такой пары взято ровно одно слово — и это верно для пар по любому разряду. Возьмите x ∈ C и вектор y, отличающийся от x в двух разрядах i и j. Попадёт ли y в C?

    Ответ

    Максимум 2ⁿ⁻¹. Таких кодов два: все векторы чётного веса и все векторы нечётного веса.

    Решение

    Оценка. Код обнаруживает одну ошибку ⇔ d(C) ≥ 2 ⇔ никакие два слова не соседние. Разобьём куб на 2ⁿ⁻¹ пар {v, v с изменённым последним разрядом}. Слова в паре соседние, поэтому из каждой пары в код попадает не больше одного: |C| ≤ 2ⁿ⁻¹. Код всех векторов чётного веса имеет 2ⁿ⁻¹ слов, и d = 2 (задача 17), так что оценка достигается.

    Единственность. Пусть |C| = 2ⁿ⁻¹. Тогда для любого разряда i из каждой пары векторов, отличающихся только в i-м разряде, в C ровно один вектор. Возьмём x ∈ C и y, отличающийся от x в разрядах i и j. Вектор z = x с изменённым i-м разрядом — сосед x, поэтому z ∉ C. Векторы z и y отличаются только в j-м разряде, и из этой пары в C ровно один; z не в C, значит y ∈ C. Итак, вместе с x в C лежат все векторы на расстоянии 2 от него, а по цепочке — все векторы той же чётности веса, что и x. Их ровно 2ⁿ⁻¹, поэтому C совпадает с одним из двух кодов: «все чётного веса» или «все нечётного веса».

    Задача 21 (программа, № 4)

    ★★★ сложная

    «Найти среднюю размерность грани в булевом кубе \(\mathbb{Z}_2^n\) размерности n.»

    Заметки есть запись

    Решайте в тетради, а сюда запишите итоговый ответ или место, где застряли. Заметка хранится в этом браузере.

    Подсказка

    Грань записывается словом длины n из символов 0, 1, ∗ (как ∗0∗10). Сколько всего граней? В скольких из них i-й символ — звёздочка?

    Ответ

    n/3 (вершины считаются гранями размерности 0).

    Решение

    Граней столько же, сколько слов длины n над {0, 1, ∗}: 3ⁿ. Размерность грани — число звёздочек. В i-м разряде звёздочка стоит ровно у 3ⁿ⁻¹ граней (остальные разряды произвольны). Сумма размерностей = n·3ⁿ⁻¹, среднее = n·3ⁿ⁻¹ / 3ⁿ = n/3.

    Задача 22 (программа, № 5)

    ★★★ сложная

    «Пусть S — некоторая сфера радиуса r в булевом кубе размерности n. Вычислить \(\sum_{x, y \in S} d(x, y)\).»

    Заметки есть запись

    Решайте в тетради, а сюда запишите итоговый ответ или место, где застряли. Заметка хранится в этом браузере.

    Подсказка

    Сдвиг на центр (x ↦ x ⊕ a) не меняет расстояний, поэтому считайте центр нулевым: S — все векторы веса r. Считайте вклад каждого разряда отдельно.

    Ответ

    Если сумма по упорядоченным парам (x, y): \(2n\binom{n-1}{r-1}\binom{n-1}{r}\). По неупорядоченным парам — вдвое меньше: \(n\binom{n-1}{r-1}\binom{n-1}{r}\).

    В условии не уточнено, упорядоченные ли пары Запись Σ по x, y ∈ S обычно означает упорядоченные пары. На экзамене стоит назвать оба ответа.

    Решение

    Пусть центр нулевой. В i-м разряде единица стоит у \(\binom{n-1}{r-1}\) векторов сферы, ноль — у \(\binom{n-1}{r}\). Упорядоченная пара даёт 1 в i-м разряде расстояния, если у одного вектора там 1, а у другого 0: таких пар \(2\binom{n-1}{r-1}\binom{n-1}{r}\). Суммируем по n разрядам. Проверка при n = 2, r = 1: S = {10, 01}, сумма по упорядоченным парам 2 + 2 = 4, формула даёт 2·2·1·1 = 4.

    Задача 23 (программа, № 6)

    ★★★ сложная

    «Пусть S — некоторая сфера радиуса r с центром a ∈ \(\mathbb{Z}_2^n\). Найти сумму \(\bigoplus_{x\in S} x\).»

    Заметки есть запись

    Решайте в тетради, а сюда запишите итоговый ответ или место, где застряли. Заметка хранится в этом браузере.

    Подсказка

    Каждый x ∈ S записывается как a ⊕ e, где ‖e‖ = r. Тогда сумма = (|S| mod 2)·a ⊕ (сумма всех векторов веса r). Чему равен i-й разряд последней суммы?

    Ответ
    \[ \begin{aligned} &\left(\tbinom{n}{r} \bmod 2\right)\cdot a \\ \oplus\; &\left(\tbinom{n-1}{r-1} \bmod 2\right)\cdot(11\dots1) \end{aligned} \]
    Решение

    Слагаемых a в сумме |S| = \(\binom{n}{r}\), а a ⊕ a = 0, поэтому от них остаётся a при нечётном \(\binom{n}{r}\) и 0 при чётном. В сумме всех векторов веса r i-й разряд равен числу таких векторов с единицей в i-м разряде, по модулю 2, то есть \(\binom{n-1}{r-1}\) mod 2, — одинаково для всех разрядов. Проверка: n = 2, r = 1, a = 00: S = {10, 01}, сумма 11; формула: \(\binom{2}{1}\) = 2 чётно, \(\binom{1}{0}\) = 1 нечётно — получаем 11.
